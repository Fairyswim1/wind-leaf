# 윈드 리프

손의 세 카드 중 하나를 놓거나 다음 도감으로 보내며, 십의 자리별 줄기에 일의 자리 잎을 작은 순서로 채우는 12라운드 퍼즐. 같은 값은 각각 한 장씩 기록합니다.

`npm test`, `npm run build`, `npm start`로 독립 실행합니다. Vercel: Other, build `npm run build`, output `dist`.

원작 참고: Lost Cities의 오름차순 열과 카드 처리 후 보충. 자체 그래픽·공개 덱·줄기/잎·중복·목표 칸으로 변형. 원작 에셋 미사용.

교육과정 9수04-02 중 줄기와 잎 그림만 다룹니다. 퍼즐의 카드 선택과 실제 전체 자료 정리를 구분하며, 여행 노트의 8개 새로운 과제로 표현·해석 증거를 기록합니다. 승리나 점수로 공식 이수를 판정하지 않습니다. 기록은 현재 브라우저에만 저장됩니다.
